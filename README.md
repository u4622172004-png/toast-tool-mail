📧 Toast Mail Tool

Toast Mail Tool è un tool CLI in Node.js che permette di creare e gestire email anonime.

Con questo tool puoi:

- creare email anonime
- controllare la inbox
- leggere i messaggi completi
- gestire più account
- ricevere notifiche quando arrivano nuove email

---

⚡ Installazione

Clona il repository da GitHub:

git clone https://github.com/u4622172004-png/toast-tool-mail

Entra nella cartella del progetto:

cd toast-tool-mail

Installa le dipendenze:

npm install

---

🚀 Avvio del tool

Per avviare il programma esegui:

node index.js

---

📥 Funzioni

Il tool include le seguenti funzioni:

1. Creazione email temporanea
2. Controllo inbox
3. Lettura messaggi completi
4. Reset email
5. Controllo inbox di tutti gli account
6. Notifica automatica quando arriva una nuova email
